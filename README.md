# ABTalks — 30 Days Coding Challenge

ABTalks is a gamified coding platform designed to help students stay consistent through daily challenges, streaks, community interaction, XP, and leaderboards.

## 📄 `prompt.md`

`prompt.md` contains the complete project requirements, page structure, UI/UX guidelines, navigation, technical requirements, and development instructions.

Use it as the **main reference when working on the project with Claude Code**.

## 🚀 Usage

Place `prompt.md` in the project root and tell Claude Code:

```text
Read prompt.md first. Use it as the source of truth for this project.
Inspect the existing files before making changes and preserve the
existing design, functionality, and structure unless instructed otherwise.
```

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Mobile-first 390px design
* Dark theme with orange accents

**Goal:** Learn. Build. Stay Consistent. Rise Together.
